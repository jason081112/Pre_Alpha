FLOWSTEP / 从记录到对话

四步，让一个人格活起来

每一步都有明确的输入、输出和失败方式。不是魔法，是一条可以检查的流水线。

01

导入记录

你导出的微信 / QQ 文本、CSV、HTML 或 JSON，先在本地规范化。原文不离开设备。

TXT · CSV · HTML · JSON
02

蒸馏人格

Distilly 拆出六层：硬规则 → 身份 → 表达 → 决策 → 人际 → 纠错。推断必须带依据。

Distilly
03

桥接

profile2soul 把文本人格翻译成 SOUL.md、style seeds、五维驱力和长期记忆。

profile2soul
04

开始对话

OpenHer 在云端跑一轮，Web/PWA 实时流式显示；多段消息会像真人一样一条条发来。

OpenHer · WS
⌁

边界：上传的是结构化人格，不是聊天原文。精修接口见到 raw_text、messages、chat_log 会直接拒绝。
