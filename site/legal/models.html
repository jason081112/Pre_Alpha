模型披露

版本 1.0 · 运营主体：Wang Xinyu · 随服务端配置自动生成

Pre_Alpha 不自己训练基础模型。对话由第三方大模型服务生成，我们负责角色设定、上下文组装、额度与内容审核。本页列出当前实际可用的模型，方便你判断对话内容会发送给谁。

1. 平台默认模型

未绑定自己的 API Key 时，对话走平台额度，使用：

  • 服务商：dashscope
  • 模型：qwen-plus-latest

平台额度有每日上限，用完后需要等到次日，或绑定自己的 Key 继续。平台额度下的对话内容同样会发送给上述服务商，处理方式见《隐私政策》。

3. 内容审核

输入侧在生成前做一次安全检查；输出侧在返回前做规则审核。命中高风险内容时，回复会被替换为安全提示，或在不改变原意的前提下追加求助信息。处置与申诉规则见《可接受使用政策》。

审核是确定性的本地规则加上游内容过滤，不保证覆盖所有语义变体。发现漏审内容可以通过应用内「举报」或邮件反馈。

4. 变更

新增或下线服务商、模型时，本页随服务端配置一起更新。若变更会影响数据处理方式，我们会在《隐私政策》中同步说明并重新征得同意。
