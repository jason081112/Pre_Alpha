# Provider 条款快照

用于存放 `docs/provider-training-policy.md` 里引用的条款留证，供非技术同事与审计复核。

## 命名

```
<provider>-<YYYY-MM-DD>-<内容>.md|pdf|html
```

例：`dashscope-2026-12-01-privacy-policy.pdf`

## 要求

- 只存与「是否训练 / 保留期 / opt-out」相关的页面或条款段落，不必整站打包
- 优先存 PDF 或纯文本；HTML 需去掉脚本与样式，避免把追踪代码带进仓库
- 同时在训练政策文档对应小节填写「条款快照」文件名与核对日期
- 条款涉及机密或不允许再分发的，存文件名 + 保存位置（公司网盘）而非内容本身
