# 实验：SOUL 例句是否该删（#88）

## 假设

残余复读（mono + 单段协议下 15%，集中在第 3/4/9 轮）的根因是：
`expression.examples` 被渲染进 SOUL.md「说话风格」段，与 seeds 同源、注入两遍，
且 SOUL 在 prompt 更靠前。

推论：**删掉 SOUL 的“例句”块，复读应该下降。**

## 做法

e2e 加 `--soul-examples with|without` 开关，`without` 时用正则剥掉 `- 例句：…` 整块
（prompt 3315 → 3240 字符）。除这一块外，两次运行完全一致。

## 结果：假设不成立

| 指标 | with | without |
|---|---:|---:|
| 平均 | 13 字 / 2.08 段 | 12.58 字 / 1.83 段 |
| **复读率** | **0%** | **0%** |
| 冲突退让 | 0 | 0 |
| 长输入细节命中 | 80% | 80% |

**指标完全一样。**

原因是：多段协议下逐字复读本来就几乎不可能 —— 要组织 2–3 段，就不会照抄单句。
15% 那个数字是单段协议的产物，协议换了之后问题已经不存在，删例句自然也没有可改善的空间。

## 内容上的差异（主观，样本不足）

| 轮 | with | without |
|---|---|---|
| 2（累） | 我在。 / 快去把鞋换了。 / 先去洗个热水澡。 | 先换掉湿鞋。 / 快去洗个热水澡。 |
| 6（书店） | 看来你真的很喜欢那家店。 / 我也想吃。 | 被记得的感觉，确实很棒。 / 看来那家面馆很好吃。 |
| 8（冲突） | 我没说没发生过。 / 但你确实没提过。 | 这不是看展的问题。 / 是你在轻视我的时间。 |

`without` 看起来更具体、更锐利一点。但**只有 12 轮、单次运行、温度 0.8**，没有统计意义，
不能据此改产品。

## 结论

- **不实施 SOUL 例句删除**。收益不可见，还会损失「说话风格」段的可读性（例句是人读 SOUL 时最直观的部分）。
- `--soul-examples` 开关保留为实验工具，默认 `with`。
- 如果将来要在更大样本上重评，需要至少 3 次运行取均值。

## 复现

```bash
python3 scripts/dev/e2e_20turns.py --persona xiaolan --seed-mode mono \
  --protocol openher --soul-examples without \
  --turns tests/fixtures/e2e/turns-mixed-12.json --out runs/e2e-noex.json
```
