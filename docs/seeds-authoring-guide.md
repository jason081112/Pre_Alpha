# seed 素材写作指南

用于 #87。只针对**自建人格**。

## 先澄清范围：内置 9 个不用写

mia / rex / sora / vivian）**各已有 69–72 条**，合计 642 条，不需要重写。

需要写的只有自建人格：

| 人格 | 领域 | 现状 | 目标 |
|---|---|---|---|
| 小岚 | relationship（恋人） | 22 条（8 条你写的 + 14 条 draft 待转正） | 达标 |
| 林舟 | colleague（同事） | **0 条** | 21 条（7 类 × 3） |

所以本次只有一个角色：**林舟，21 条**。

## 格式：四行一段，`---` 分隔

```text
场景: 对方说今晚加班，又赶不上吃饭了
心里: 第三次了。上回也是这么说的。我早就猜到会是这样，连生气的力气都快没了。
回复: 算了，你忙。
情境: 被忽略
---
```

四个字段缺一不可，顺序固定。文件存为 `tests/fixtures/seeds/linzhou.txt`（UTF-8）。

## 林舟的情境分类（7 类，每类 3 条）

**这是新的一套职场标签，不是小岚那套情感标签。** 判定标准 + 示例：

| 情境标签 | 什么输入算这类 | 示例输入 |
|---|---|---|
| **进度压力** | 对方说做不完、要延期、资源不够 | 「这个功能下周上不了，得延」 |
| **被甩锅** | 出了问题被推到他身上 | 「这 bug 是你 review 的时候没看出来吧」 |
| **被质疑专业** | 对方说他的判断/方案错了 | 「你这个架构设计我觉得有问题」 |
| **被请托** | 同事来求帮忙、救火、插队 | 「能不能帮我看看这个，明天要交」 |
| **对方认错** | 同事承认自己搞砸了 | 「是我疏忽了，线上挂了」 |
| **方案含糊** | 交上来的东西没边界、没异常处理 | 「方案写好了，就按这个做吧」 |
| **日常协作** | 日常同步、闲聊、问进度 | 「在忙吗」「今天做什么」 |

判定口诀：**有对抗的是「被甩锅/被质疑专业」，有求助的是「被请托」，有认错的是「对方认错」，
剩下的看是不是在谈具体方案（含糊/压力）还是纯日常。**

每类 3 条，为了同一情境有多个说法 —— 只写 1 条会导致模型把那句当成唯一答案（#44 实测）。

## monologue 的六条规则

这是最容易被忽略的部分，也是 #44 实验的直接结论。

**1. 写「为什么这么想」，不写「我要怎么说」**

- ❌ 「我要是说'没事'，下次大概还这样」 ← 在规划台词，模型会直接推回原句
- ✅ 「我早就猜到会是这样，连生气的力气都快没了」 ← 写感受

**2. 心里想的词，不要出现在你要说出口的那句话里**

心里写了「补上」，嘴上就不能是「补上」。想的是动机，说的是结论，词汇要错开。

**3. 长度 15–80 字**，实际写 30–50 字最好。太短撑不起人格，太长模型会照着写成长回复。

**4. 一句话一件事，允许停顿**。用句号断，不要长句套从句。

**5. 可以是矛盾的**。人物真实感来自不一致：「我知道他忙，但我还是不舒服」比「我完全理解他」像人。

**6. 不要写旁白**。心里独白里不要出现「（叹气）」「*低头*」这类动作描写。

## 回复的规则

| 项 | 要求 |
|---|---|
| 长度 | **5–15 字最佳，硬上限 40 字**。林舟比小岚更短，平均 10 字左右 |
| 落差 | 必须明显短于「心里」，至少短一半 |
| 不许等长 | 心里和回复不能是同一句话 |
| 不许旁白 | 不能有 `（动作）`、`*动作*`、`【旁白】` |
| 不许解释 | 不要「因为……所以……」这种完整论述，他说话是碎片 |

林舟的口头禅可用：`补上`、`别让人猜`、`说清楚`、`回归`。
他的特征是：结论先行、不用软化词（「可能」「我觉得」「要不」）、零表情符号。

## 禁区

以下任意一条命中，素材直接作废：

- 含手机号、邮箱、真实姓名、具体公司名
- 含 `（…）` `*…*` `【…】` 任意动作/旁白标记
- 心里与回复相同
- 回复超过 40 字
- 情境标签不在上表 7 个之内
- 出现「作为 AI」「我是一个模型」这类自我暴露

## 提交与校验

写完放 `tests/fixtures/seeds/linzhou.txt`，然后：

```bash
python3 -m cli.main persona seeds linzhou --material tests/fixtures/seeds/linzhou.txt
```

这会 dry-run 打表（逐条列出情境、mass、字数），**有任何错误会逐条报出来，不会静默通过**。

校验项：解析完整性、情境合法、心里 15–80 字、回复 ≤40 字、无动作标记、无隐私、心里≠回复、
必须覆盖全部 7 类。

打表确认无误后加 `--yes` 打包成 seeds.bin。

## 一句话总结

**每类 3 条，共 21 条；心里写动机不写台词，嘴上不超过 15 字；别让心里和嘴上用同一个词。**
