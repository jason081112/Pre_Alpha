# 实验：多段素材到底有没有用（#87 盘点）

## 背景

盘点素材缺口时发现：**上游 324 条中文 reply 里，含换行的是 0 条** —— 上游素材全是单段。
而我们给小岚补了 4 条多段素材（`回复: a / b / c`），属于偏离上游做法。

推论一度是「不该补」。所以做对照验证：**26 条（含 4 条多段）vs 22 条（去掉多段）**。

## 结果：有用，但作用不在「段数」

| 指标 | 26 条（含多段） | 22 条（无多段） |
|---|---:|---:|
| 平均 | 13 字 / 2.08 段 | 13.25 字 / 2 段 |
| **长输入细节命中** | **80%** | **40%** |
| 复读 | 0% | 0% |

**段数几乎没差别（2.08 vs 2）** —— 因为多段输出是协议允许的，不需要素材示范。

真正的差别是**接不接得住具体事**：

| 轮 | 含多段素材 | 无多段素材 |
|---|---|---|
| 4（被骂） | 不早了。 / 想哭就哭出来吧。 | 我在听。 / 别想太多，你已经很努力了。 |
| 8（冲突） | 我没说没发生过。 / 但你确实没提过。 | 我知道。 / 我没想过就这样跳过去。 |
| 11（崩溃） | 不矫情。 / 我在听。 | 不矫情。 / 跟我说说，我都听着。 |

无多段素材时，第二段容易滑向「别想太多」「我已经很努力了」这类**空泛安慰**。

## 结论：多段素材的价值是「示范怎么用后段接细节」

不是教它分段（协议已经允许），而是展示这个模式：

```
先坐会儿。        ← 态度
中午那两口哪够。   ← 接住具体细节
我给你叫碗面。     ← 给行动
```

所以：
- **保留**小岚的 4 条多段素材
- **建议给林舟也补**（他 21 条全是单段，长输入时会滑向空泛）
- 上游没有多段素材，不代表我们不该有 —— 上游的 few-shot 是把 monologue 和 reply 一起给的（`full` 模式），信息量不同

## 局限

- 5 个长输入 × 单次运行，温度 0.8。样本小，方向可信但幅度不稳。
- 第 6 轮反例：无多段时 overlap=4（"看来那个蛋很有用"重复了场景词），高重合不等于接得好。
