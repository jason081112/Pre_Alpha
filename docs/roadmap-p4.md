## 与 P3 的衔接

P3 交付的是「产物」（SOUL.md / seeds.bin / 纠错层 / 记忆层），P4 要让这些东西**被真实用户
经由界面操作产生和消费**。所以 P4 的验收口径不能只看接口返回 200，要看：

- 用户能否从一个原始对话记录，走完「蒸馏 → 预览 → 试聊 → 保存」全程
- 试聊时的表现是否与 P3 的验收口径一致（`docs/e2e-protocol.md`）
- 每个人的数据是否隔离（换用户看不到别人的人格）
